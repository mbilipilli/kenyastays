# Kenya Stays

Create a Kenyan Airbnb‑style platform where:

Owner Portal: Property owners can register, log in, and manage listings (upload photos, set prices in KES, update availability).

Client Portal: Travelers can sign up, search, and book secure short‑term rentals (apartments, lodges, homestays, guest houses).

Authentication: Include secure login with email/phone + OTP, and optional ID verification for trust.

Payments: Integrate M‑Pesa STK push and card payments for seamless local transactions.

Availability: Show real‑time unit availability with instant booking confirmation.

Search & Filters: Clients can filter by city (Nairobi, Mombasa, Kisumu, Naivasha, Maasai Mara), price, amenities (Wi‑Fi, parking, breakfast), and proximity to landmarks.

Reviews & Ratings: Guests leave feedback; hosts build credibility.

Mobile First: Optimize for smartphone users, with a clean, WhatsApp‑style interface.

Community Angle: Highlight eco‑friendly and community‑run homestays to appeal to CSR‑minded travelers.

Scalability: Backend ready for expansion into East Africa.
